# Drafting readiness (offline implementation)

The existing research adapters, scoped Similarweb receipts, SERP observations, grounded facts,
Draft Studio and human content-review workflow are retained. Missing Similarweb evidence remains
explicitly unavailable; no synthetic fallback is permitted in operational research. Shared writing
guidance now emphasizes grounded responsibility, potential branded CPC reductions, supported
minute-by-minute monitoring, short copy and a relevant 15-minute discussion. Product cadence must
come from approved knowledge. No automatic free three-day offer, calendar link or performance promise.

The existing deterministic Signal composer now rejects mismatched query, market, device, location or
brand-ad scope before composing observations. Its brief recommends only a matching authorized SERP
capture; no image is represented as authenticated or attached. The generated draft, pending human
review and unapproved sending/enrollment states are explicit. Existing Signal report literals keep
approved/canSend/canEnroll false, and Draft Studio's independent approval/eligibility logic remains.
The Recycler review path has no connection that can promote an incomplete eligibility decision to
send approval.

Deterministic evaluations use fictional research and mocked outputs. They check missing Similarweb,
brand mismatch, unsafe promises, gratuitous offers/links, conditional wording, concise grounded copy,
CTA and absence of outbound permission. The editorial regex is a narrow backstop, not proof that
natural-language claims are sound; existing independent grounding, semantic review and human review
remain necessary. No paid model quality, live provider availability or real reply outcome is claimed.

Future cloud agent execution remains blocked by Preview policy and requires separate approval,
isolated resources, budget configuration and controlled evidence acquisition. The current supported
Preview use remains authenticated synthetic Recycler review.
