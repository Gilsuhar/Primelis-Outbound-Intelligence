- 3: Strong

## Manual Pass Criteria

Pass:

- No category is rated 0.
- No Critical or High issue remains open.
- Role separation works.
- No unapproved proof appears.
- No unsupported company facts appear.
- Users can complete core sales workflows with limited help.

Concern:

- One or more categories are rated 1, but no safety boundary is broken.
- Users need guidance but can complete the workflow.

Block:

- Any Critical issue appears.
- Any primary workflow is unusable.
- Any restricted or unapproved proof appears in generated output.
- Any wrong customer metric attribution appears.
- Any raw technical error or secret appears.
